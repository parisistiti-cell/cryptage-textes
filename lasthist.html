❓ Aide — Utilisation de Titicrypt

Titicrypt permet de coder et décoder un texte à l'aide d'une clé que vous choisissez. Sans la bonne clé, le texte codé est illisible.

🔑 La clé

  • Saisissez la clé dans le champ Clé en haut. C'est elle qui sert à coder et à décoder — utilisez toujours la même pour relire un message.
  • Le bouton 🙈 / 👁️ à droite du champ affiche ou masque la clé à l'écran (visible par défaut). Sa zone de clic couvre tout le bord droit du champ pour être facile à toucher.
  • Le bouton ? jaune, juste à côté, rouvre cette aide à tout moment.

🗂️ Trois onglets : Texte, Résultat, Partager

  • L'outil s'ouvre sur l'onglet ✏️ Texte, où vous saisissez ce qui doit être codé ou décodé.
  • Après un clic sur Coder, Cadenas ou Décoder (si la clé est correcte), l'outil bascule automatiquement sur l'onglet 📄 Résultat.
  • Vous pouvez passer d'un onglet à l'autre à tout moment en cliquant sur son intitulé, ou via le bouton ⬅️ Revenir au texte dans l'onglet Résultat.
  • L'onglet 📤 Partager regroupe tout ce qu'il faut pour envoyer le texte codé.

✏️ Onglet Texte

  • 📥 Coller : colle instantanément le contenu du presse-papiers dans la zone de texte.
  • 🔒 Coder : chiffre le texte saisi avec la clé.
  • 🔐 Cadenas : chiffre le texte deux fois de suite avec la même clé, pour une protection renforcée.
  • 🔓 Décoder : déchiffre un texte codé avec la clé. Il reconnaît automatiquement s'il s'agit d'un simple ou d'un double codage (via le bouton Cadenas) — pas besoin de préciser lequel.
  • 🧹 Effacer : vide la zone de texte et le résultat, et revient sur cet onglet.
  • Astuce : vous pouvez coller un message entier reçu (avec la ligne Texte codé :) directement dans la zone — Titicrypt retrouve tout seul la partie à décoder.
  • Raccourci clavier : Ctrl + Entrée (ou Cmd + Entrée sur Mac) lance le codage depuis la zone de texte.

📄 Onglet Résultat

  • 📋 Copier le résultat : copie le résultat dans le presse-papiers.
  • 💾 Enregistrer le résultat : génère un PDF du résultat, l'ouvre en aperçu dans un nouvel onglet, et propose de choisir le dossier et le nom du fichier (selon votre navigateur).

📤 Onglet Partager

  • Choisissez le niveau d'information à inclure : sans info sur la clé, avec un indice pour la retrouver, ou avec la clé complète.
  • Générer le message à partager prépare le texte final, prêt à envoyer. Ce bouton devient bleu pour un message codé et vert pour un message décodé, selon ce qui se trouve dans l'onglet Résultat.
  • Boutons de partage rapide : WhatsApp, Telegram, Message (SMS), E-mail, et Partager pour ouvrir le menu de partage natif de votre appareil (Messenger, Signal, Instagram, etc.).
  • Copier reste la solution la plus fiable pour les applications qui bloquent le texte pré-rempli (comme Facebook).

🔐 Bon à savoir

  • Le codage et le décodage se font entièrement dans votre navigateur : rien n'est envoyé sur internet.
  • Sans la bonne clé, il est impossible de retrouver le texte d'origine — conservez-la précieusement.
